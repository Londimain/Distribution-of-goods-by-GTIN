# 📦 Распределение кодов маркировки по товарам

**Версия: 1.2.0**

Приложение с графическим интерфейсом (на базе Python и Kivy) для автоматического распределения отсканированных кодов маркировки (GS1 DataMatrix) по отдельным текстовым файлам в зависимости от товара.

## 📝 Описание

Программа считывает текстовый файл с отсканированными кодами (обычно строки начинаются с `01` + GTIN), сопоставляет их с вашей базой товаров и раскладывает по отдельным файлам. Это позволяет быстро подготовить данные для отчетности или дальнейшей обработки.

## ✨ Основные возможности

- **База данных товаров (SQLite):** Удобное добавление, редактирование и удаление товаров (Название, Объём, GTIN).
- **Быстрый поиск:** Мгновенная фильтрация таблицы товаров по названию и GTIN.
- **Умное распределение с валидацией:** Перед разделением программа проверяет файл. Если найдутся коды товаров, которых нет в базе, разделение отменяется, а пользователю показывается список недостающих GTIN.
- **Удобное копирование и вставка:** 
  - Нажмите левой кнопкой мыши на любой недостающий GTIN в окне ошибки, чтобы мгновенно скопировать его в буфер обмена.
  - В полях ввода программы работает вставка по правой кнопке мыши (текст вставляется сразу, без лишних меню). Для поля GTIN буквы и пробелы отфильтровываются автоматически.
- **Drag-and-Drop:** Вы можете выбрать файл для разделения через диалоговое окно или просто перетащить его из Проводника прямо в окно программы.
- **Автосоздание папок:** Для каждого разделенного файла создается отдельная папка с его именем, где и сохраняются результаты.
- **Форматирование имен:** Итоговые файлы сохраняются с понятным именем: `Название - Объём (Количество) - GTIN.txt`.
- **Поддержка кодировок:** Автоматическое определение кодировки исходного файла (UTF-8, Windows-1251, Latin-1).
- **Современный интерфейс:** Темная тема, вкладки, адаптивное окно, центрирование по экрану.

## 🚀 Установка и запуск

Для запуска из исходного кода вам потребуется **Python 3.8+**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Londimain/Distribution-of-goods-by-GTIN.git
   cd Distribution-of-goods-by-GTIN
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для macOS/Linux:
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   python -m pip install --upgrade pip
   pip install kivy pywin32
   ```
   *(Пакет `pywin32` необходим для корректной работы системного окна выбора файлов на Windows).*

4. Запустите программу:
   ```bash
   python main.py
   ```

## 🛠️ Сборка в .exe (Windows)

Для сборки автономного исполняемого файла используется **PyInstaller**.

Убедитесь, что у вас установлен PyInstaller:
```bash
pip install pyinstaller
```

Откройте PowerShell в папке с проектом и выполните следующую команду (она очистит старые файлы сборки и соберет новый `.exe` с иконкой и всеми ресурсами):

```powershell
# Очистка предыдущих сборок
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force __pycache__ -ErrorAction SilentlyContinue

# Сборка проекта (обратите внимание на флаг --hidden-import win32timezone)
pyinstaller --onefile --windowed --name CodeSplitter --icon="ico/distribution.ico" --add-data "ico;ico" --hidden-import win32timezone main.py
```

Готовый файл `CodeSplitter.exe` появится в папке `dist`.

## 📖 Инструкция по использованию

1. **Вкладка «Товары»**:
   - Заполните поля: Название, Объём (необязательно) и GTIN (14 цифр).
   - Нажмите «Добавить». Все товары отображаются в таблице.
   - Используйте строку поиска для быстрого нахождения нужного товара.
   - Кнопки «Изменить» и «Удалить» позволяют управлять записями.
   - *Совет:* Нажмите правую кнопку мыши в любом поле ввода, чтобы вставить скопированный текст из буфера обмена.

2. **Вкладка «Разделить файл»**:
   - Выберите `.txt` файл с кодами маркировки двумя способами:
     - Нажмите кнопку **«Обзор файла»**.
     - Или просто **перетащите файл** из Проводника Windows в специальную зону в окне программы.
   - Нажмите «Разделить».
   - **Проверка базы:** Если программа найдет в файле коды товаров, которых нет в вашей базе, она остановит процесс и покажет окно с их GTIN. Нажмите на нужный GTIN, чтобы скопировать его, перейдите на вкладку «Товары», добавьте товар и повторите попытку.
   - Если все товары известны базе, рядом с исходным файлом создастся папка с его именем, внутри которой будут лежать файлы для каждого товара.
   - Уведомление об успехе или ошибке появится прямо в строке пути к файлу.

## 📂 Структура проекта

- `main.py` — точка входа, настройка окна и вкладок.
- `db.py` — работа с базой данных SQLite.
- `widgets.py` — кастомные элементы интерфейса (кнопки, вкладки, ячейки таблиц, поле ввода с поддержкой правого клика, зона Drag-and-Drop).
- `tab_products.py` — логика вкладки управления товарами.
- `tab_splitter.py` — логика вкладки разделения файлов и валидации GTIN.
- `tab_about.py` — вкладка с описанием и ссылками.
- `utils.py` — вспомогательные функции (валидация, чтение файлов, всплывающие окна).
- `ico/` — папка с иконками.
