# 📦 Распределение кодов маркировки по товарам

Приложение с графическим интерфейсом (на базе Python и Kivy) для автоматического распределения отсканированных кодов маркировки (GS1 DataMatrix) по отдельным текстовым файлам в зависимости от товара.

## 📝 Описание

Программа считывает текстовый файл с отсканированными кодами (обычно строки начинаются с `01` + GTIN), сопоставляет их с вашей базой товаров и раскладывает по отдельным файлам. Это позволяет быстро подготовить данные для отчетности или дальнейшей обработки.

## ✨ Основные возможности

- **База данных товаров (SQLite):** Удобное добавление, редактирование и удаление товаров (Название, Объём, GTIN).
- **Быстрый поиск:** Мгновенная фильтрация таблицы товаров по названию, GTIN или номеру записи.
- **Умное распределение:** Программа автоматически находит коды, принадлежащие товарам из базы, и раскладывает их в отдельные файлы.
- **Автосоздание папок:** Для каждого разделенного файла создается отдельная папка с его именем, где и сохраняются результаты.
- **Форматирование имен:** Итоговые файлы сохраняются с понятным именем: `Название - Объём (Количество) - GTIN.txt`.
- **Поддержка кодировок:** Автоматическое определение кодировки исходного файла (UTF-8, Windows-1251, Latin-1).
- **Современный интерфейс:** Темная тема, вкладки, адаптивное окно, центрирование по экрану.

## 🚀 Установка и запуск

Для запуска из исходного кода вам потребуется **Python 3.8+**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Londimain/Work-schedule.git
   cd Work-schedule
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для macOS/Linux:
   source venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   python -m pip install --upgrade pip
   pip install kivy
   ```

4. Запустите программу:
   ```bash
   python main.py
   ```

## 🛠️ Сборка в .exe (Windows)

Для сборки автономного исполняемого файла используется **PyInstaller**.

Убедитесь, что у вас установлен PyInstaller:
```bash
pip install pyinstaller
```

Откройте PowerShell в папке с проектом и выполните следующую команду (она очистит старые файлы сборки и соберет новый `.exe` с иконкой и всеми ресурсами):

```powershell
# Очистка предыдущих сборок
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force __pycache__ -ErrorAction SilentlyContinue

# Сборка проекта
pyinstaller --onefile --windowed --name CodeSplitter --icon="ico/distribution.ico" --add-data "ico;ico" main.py
```

Готовый файл `CodeSplitter.exe` появится в папке `dist`.

## 📖 Инструкция по использованию

1. **Вкладка «Товары»**:
   - Заполните поля: Название, Объём (необязательно) и GTIN (14 цифр).
   - Нажмите «Добавить». Все товары отображаются в таблице.
   - Используйте строку поиска для быстрого нахождения нужного товара.
   - Кнопки «Изменить» и «Удалить» позволяют управлять записями.

2. **Вкладка «Разделить файл»**:
   - Нажмите «Обзор файла» и выберите `.txt` файл с кодами маркировки.
   - Нажмите «Разделить».
   - Программа создаст рядом с исходным файлом папку с его именем, внутри которой будут лежать файлы для каждого товара (с указанием количества кодов).
   - Уведомление об успехе или ошибке появится прямо в строке пути к файлу.

## 📂 Структура проекта

- `main.py` — точка входа, настройка окна и вкладок.
- `db.py` — работа с базой данных SQLite.
- `widgets.py` — кастомные элементы интерфейса (кнопки с эффектом нажатия, стилизованные вкладки, ячейки таблиц).
- `tab_products.py` — логика вкладки управления товарами.
- `tab_splitter.py` — логика вкладки разделения файлов.
- `tab_about.py` — вкладка с описанием и ссылками.
- `utils.py` — вспомогательные функции (валидация, чтение файлов, всплывающие окна).
- `ico/` — папка с иконками.
